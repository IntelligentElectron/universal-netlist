# Schemas

Response types and data models used by the Universal Netlist MCP Server.

| Schema | Description |
|--------|-------------|
| [`universal-netlist.md`](universal-netlist.md) | Core netlist data model: components, pins, nets, and their connections. All EDA parsers convert to this unified representation. |
| [`shared-types.md`](shared-types.md) | Shared response types used across tools: component grouping, XNET traversal results, compact array behavior, DNS detection, and power/ground stop nets. |
